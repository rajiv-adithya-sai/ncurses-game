##Prerequisites
GCC compiler
Ncurses library('libncurses5-dev')

##Installation
LINUX
sudo apt-get install libcurses5-dev libncursesw5-dev

MACOS:
brew install ncurses

## INSTALLATION AND BUILD
git clone https://github.com/rajiv-adithya-sai/ncurses-game.git
cd ncurses-game

## BUILD AND RUN
make run
